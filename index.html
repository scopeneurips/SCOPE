Abstract

The application of video world models as interactive simulators encounters significant challenges in first-person shooter (FPS) games. Such environments require spatially precise and temporally coherent visual responses to millisecond-level control inputs. Current models, typically trained on isolated games with global action conditioning, fail to capture the spatial selectivity and shared action-visual dynamics universal across the FPS genre. To overcome these limitations, we introduce CrossFPS, a large-scale multi-game dataset with frame-aligned telemetry, and present SCOPE, a framework that converts a frozen pre-trained video diffusion transformer into an interactive FPS world simulator. For generalized action control across diverse environments, this framework incorporates a spatially selective action alignment module. The module integrates continuous controls via temporal self-attention and discrete events via visually-queried cross-attention, enabling independent response determination at each spatial position based on the local visual context. Mapping visual features directly to action responses, rather than memorizing game-specific assets, facilitates zero-shot cross-game generalization. Supplemented with Action Classifier-Free Guidance for tunable control intensity, empirical evaluations across seven games confirm that a jointly trained unified model achieves high action-response fidelity, precise foreground-background separation, and effective transfer to unseen environments.
